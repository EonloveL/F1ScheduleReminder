# F1赛程提醒机器人 - QQ官方Bot版本

基于QQ官方Bot API V2实现，支持频道消息推送和日程管理。

## 功能特性

- ✅ **频道消息推送** - 比赛提醒、结果推送、每日赛程汇总
- ✅ **日程自动管理** - 每周自动创建本周比赛日程（周一或周二）
- ✅ **双频道配置** - 公告频道 + 实时数据频道分离
- ✅ **智能特殊处理** - 拉斯维加斯站等特殊赛程自动调整更新时间
- ✅ **赛前提醒** - 支持多种提醒时间配置

## 前置要求

1. **QQ开放平台账号**
   - 访问 https://q.qq.com 注册
   - 个人或企业主体均可

2. **机器人权限**
   - 将机器人添加到QQ频道
   - 设置为频道管理员（创建日程需要）

## 快速开始

### 1. 安装依赖

```bash
cd qq_official_version
pip install -r requirements.txt
```

### 2. 配置机器人

编辑 `main.py`，填写以下配置：

```python
# QQ开放平台配置
APPID = "你的AppID"
APP_SECRET = "你的AppSecret"

# 频道配置（获取方法：在QQ频道中右键子频道 -> 复制子频道ID）
ANNOUNCEMENT_CHANNEL_ID = "公告子频道ID"
LIVE_DATA_CHANNEL_ID = "实时数据子频道ID"
SCHEDULE_CHANNEL_ID = "日程子频道ID"  # 可选，不填则使用公告频道
```

### 3. 运行机器人

```bash
python main.py
```

## 配置说明

### 频道ID获取方法

1. 在QQ频道中右键点击子频道
2. 选择"复制子频道ID"
3. 粘贴到配置中

### 提醒时间配置

```python
REMINDER_TIMES = {
    "fp1": 30,           # 第一节练习赛提前30分钟
    "fp2": 30,           # 第二节练习赛提前30分钟
    "fp3": 30,           # 第三节练习赛提前30分钟
    "qualifying": 30,    # 排位赛提前30分钟
    "sprint": 30,        # 冲刺赛提前30分钟
    "race": 60,          # 正赛提前60分钟
}
```

### 特殊赛程处理

机器人会自动识别以下特殊赛程，并在周二（而非周一）创建日程：

- Las Vegas Grand Prix（拉斯维加斯站）
- Qatar Grand Prix（卡塔尔站）

这些比赛的正赛通常在次周周一中午12点（北京时间）举行。

## 工作流程

### 每周日程更新

1. **正常周**：每周一上午8:00自动创建本周比赛日程
2. **特殊周**（拉斯维加斯等）：周二上午8:00创建日程
3. 创建日程后，自动发送赛程预览消息

### 比赛提醒

- 在比赛开始前X分钟（可配置）发送提醒消息
- 提醒包含：@全体成员、比赛名称、赛道、时间

### 赛后结果

- 比赛结束后30分钟（可配置）自动推送结果
- 包含前十名、最快圈速等信息

### 每日更新

- 每天早上8:00更新赛程任务
- 获取未来7天的所有比赛环节

## 频率限制

- **日程创建**：单个管理员每天最多10次
- 机器人会自动处理限制，优先创建最近的比赛

## 故障排除

### 无法创建日程

- 检查机器人是否拥有频道管理员权限
- 检查今日是否已创建10个日程（达到上限）

### 无法发送消息

- 检查AppID和AppSecret是否正确
- 检查子频道ID是否正确
- 检查机器人是否已添加到频道

### Token过期

- 机器人会自动刷新Access Token（2小时有效期）
- 如果出现认证错误，重启程序即可

## 注意事项

1. **权限要求**：机器人必须是频道管理员才能创建日程
2. **私域/公域**：当前版本使用消息功能，公域和私域机器人都支持
3. **网络要求**：需要能够访问QQ开放平台API（国内网络即可）
