# 个人微信版本 - F1赛程提醒机器人

⚠️ **警告：此版本仅推荐本地测试使用，不推荐服务器部署**

使用 itchat 库模拟微信网页版登录，稳定性较差，需要扫码登录。

## ⚠️ 重要说明

### 为什么不推荐服务器部署？

1. **登录限制**：新注册账号（2017年后）无法登录网页版微信
2. **稳定性差**：服务器登录容易被检测为"异常登录"
3. **需要人工干预**：登录状态会过期，需要重新扫码
4. **封号风险**：频繁异地登录可能触发微信风控

### 推荐使用场景

- ✅ 本地电脑测试
- ✅ 临时使用
- ❌ 服务器长期运行

## 📋 配置步骤

### Step 1: 安装依赖

```bash
pip install -r requirements.txt
```

注意：此版本依赖 `itchat` 库。

### Step 2: 配置群名称

编辑 `main.py`：

```python
# 配置微信群名称（必须完全匹配）
WECHAT_GROUP_NAME = "F1车迷群"
```

### Step 3: 运行并扫码

```bash
python main.py
```

1. 程序会显示二维码
2. 用微信扫码登录
3. 登录成功后开始运行

## 🚀 本地运行

```bash
# 安装依赖
pip install -r requirements.txt

# 运行
python main.py

# 按 Ctrl+C 停止
```

## 🐛 常见问题

### Q: 提示"无法登录网页版"？

你的微信账号可能不支持网页版登录（2017年后注册的新账号）。

**解决方案**：使用企业微信版本或PushPlus版本。

### Q: 登录后很快掉线？

正常现象，网页版微信不稳定。

**解决方案**：使用其他版本。

### Q: 可以后台运行吗？

不建议，因为登录状态会过期。
