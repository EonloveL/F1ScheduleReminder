# F1赛程提醒机器人 - QQ官方群聊版本

基于QQ官方Bot API V2实现，支持QQ群聊消息推送。

## 功能特性

- ✅ **群聊消息推送** - 比赛提醒、结果推送、每日赛程汇总
- ✅ **@全体成员** - 重要提醒自动@所有人（需要机器人是群主或管理员）
- ✅ **赛前提醒** - 支持多种提醒时间配置
- ✅ **赛后结果** - 自动推送比赛结果
- ✅ **每日更新** - 每天早上更新赛程任务

## 前置要求

1. **QQ开放平台账号**
   - 访问 https://q.qq.com 注册
   - 个人或企业主体均可

2. **机器人权限**
   - 将机器人添加到QQ群
   - 设置为群管理员（可选，但建议设置以便@全体成员）

## 快速开始

### 1. 安装依赖

```bash
cd qq_group_official_version
pip install -r requirements.txt
```

### 2. 配置机器人

编辑 `main.py`，填写以下配置：

```python
# QQ开放平台配置
APPID = "你的AppID"
APP_SECRET = "你的AppSecret"

# 是否使用沙箱环境（重要！）
USE_SANDBOX = True  # 新机器人请设置为 True，通过审核后改为 False

# QQ群配置
QQ_GROUP_ID = "123456789"  # 你的QQ群号
```

**注意**：新创建的机器人只能在**沙箱环境**测试（`USE_SANDBOX = True`），通过审核后才能使用正式环境。

### 3. 运行机器人

```bash
python main.py
```

## 配置说明

### 获取AppID和AppSecret

1. 访问 https://q.qq.com
2. 登录后创建机器人
3. 进入机器人管理页面
4. 在"开发设置"中找到AppID和AppSecret

### 获取QQ群号

1. 打开QQ群资料
2. 查看群号（通常是5-10位数字）

### 提醒时间配置

```python
REMINDER_TIMES = {
    "fp1": 30,           # 第一节练习赛提前30分钟
    "fp2": 30,           # 第二节练习赛提前30分钟
    "fp3": 30,           # 第三节练习赛提前30分钟
    "qualifying": 30,    # 排位赛提前30分钟
    "sprint": 30,        # 冲刺赛提前30分钟
    "race": 60,          # 正赛提前60分钟
}
```

## 工作流程

### 比赛提醒

- 在比赛开始前X分钟（可配置）发送提醒消息
- 提醒会自动@全体成员（如果机器人有权限）
- 包含比赛名称、赛道、时间等信息

### 赛后结果

- 比赛结束后30分钟（可配置）自动推送结果
- 包含前十名、最快圈速等信息

### 每日更新

- 每天早上8:00更新赛程任务
- 获取未来7天的所有比赛环节

## 故障排除

### 无法发送消息

- 检查AppID和AppSecret是否正确
- 检查QQ群号是否正确
- 检查机器人是否已添加到QQ群

### 无法@全体成员

- 机器人需要是群管理员才能@全体成员
- 如果不是管理员，消息也能发送，但不会@所有人

### Token过期

- 机器人会自动刷新Access Token（2小时有效期）
- 如果出现认证错误，重启程序即可

## 注意事项

1. **权限要求**：建议将机器人设置为群管理员，以便@全体成员
2. **频率限制**：请遵守QQ官方API的频率限制
3. **网络要求**：需要能够访问QQ开放平台API（国内网络即可）
