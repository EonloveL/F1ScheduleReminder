# F1赛程提醒机器人 - QQ版本部署指南

## ⚠️ 重要：风控风险说明

### 风险等级：中高

QQ机器人使用**非官方协议**（go-cqhttp），存在被腾讯风控的风险。

---

## 📊 风控风险详解

### 1. 账号被封概率

| 账号类型 | 被封概率 | 说明 |
|---------|---------|------|
| **新注册小号** | ⚠️⚠️⚠️⚠️⚠️ **极高(80%+)** | 24小时内大概率被封 |
| **注册1-6个月** | ⚠️⚠️⚠️ **中等(40%)** | 可能被限制发言或冻结 |
| **注册6-12个月** | ⚠️⚠️ **较低(20%)** | 偶尔有验证弹窗 |
| **注册1年以上** | ⚠️ **低(10%)** | 正常使用基本安全 |
| **注册2年+老号** | ✅ **很低(5%)** | 最推荐，但别用主号 |
| **SVIP/大会员** | ✅ **低(10%)** | 腾讯对付费用户较宽容 |

### 2. 触发风控的行为

❌ **高风险行为**（千万别做）：
- 新号一登录就频繁发消息
- 短时间内发送大量相同内容
- 24小时不间断在线
- 频繁切换登录IP/设备
- 使用非常用网络环境（国外IP等）

⚠️ **中等风险**（尽量避免）：
- 每天发送超过50条消息
- 消息中包含大量链接/二维码
- 被群成员举报
- 在非正常时段频繁发消息（凌晨2-6点）

✅ **安全行为**：
- 使用老号，有正常聊天记录
- 模拟人类行为（有间歇地发消息）
- 控制发消息频率（间隔5分钟以上）
- 保持IP稳定

### 3. 账号建议

**最低要求**：
- ✅ 注册时间 **≥ 6个月**
- ✅ 有 **正常聊天记录**（不是僵尸号）
- ✅ 绑定了手机
- ✅ **不要用主号！不要用主号！不要用主号！**

**最佳选择**：
- 🌟 注册1年以上的小号
- 🌟 平时有在使用的备用号
- 🌟 SVIP/大会员（腾讯更宽容）
- 🌟 号内有一定余额（几块钱即可）

## 🚀 部署步骤

### Step 1：准备QQ号

1. **找一个符合条件的老号**（注册6个月以上）
2. **不要用主号**，用小号！
3. 确保账号能正常登录和发消息
4. 加入要推送的QQ群

### Step 2：安装 go-cqhttp

**Linux服务器**：
```bash
cd /opt
mkdir go-cqhttp && cd go-cqhttp

# 下载最新版
wget https://github.com/Mrs4s/go-cqhttp/releases/latest/download/go-cqhttp_linux_amd64.tar.gz
tar -zxvf go-cqhttp_linux_amd64.tar.gz
chmod +x go-cqhttp

# 运行配置
./go-cqhttp
```

选择通信方式时输入：**0** (HTTP)

**配置 go-cqhttp**：
编辑 `config.yml`：
```yaml
# 账号配置
account:
  uin: 你的QQ号
  password: '你的QQ密码'  # 或留空扫码登录
  
# 服务器配置
servers:
  - http:
      host: 0.0.0.0
      port: 5700
      max-row-concurrency: 1000
      middlewares:
        <<: *default
```

### Step 3：登录QQ

```bash
./go-cqhttp
```

首次运行会要求：
1. 扫码登录（推荐，更安全）
2. 或滑块验证

登录成功后，按 `Ctrl+C` 停止

### Step 4：后台运行 go-cqhttp

```bash
# 使用 nohup
nohup ./go-cqhttp > cqhttp.log 2>&1 &

# 或使用 screen
screen -S cqhttp
./go-cqhttp
# 按 Ctrl+A 然后 D 退出
```

### Step 5：部署 F1 机器人

**上传代码到服务器**：
```bash
cd /opt
mkdir f1-bot && cd f1-bot

# 上传代码...
```

**安装依赖**：
```bash
cd qq_version
pip3 install -r requirements.txt
```

**配置机器人**（已预设群号）：
编辑 `qq_version/main.py`：
```python

# 如果 go-cqhttp 在其他服务器，修改地址

```

**测试运行**：
```bash
python3 main.py
```

如果看到：
```
✓ QQ机器人初始化成功
✓ F1 API初始化成功
✓ 应用启动成功！
```

说明成功了！

### Step 6：后台运行

```bash
# 使用 screen
screen -S f1bot
python3 main.py
# 按 Ctrl+A 然后 D 退出

# 或使用 systemd（推荐）
```

## 🛡️ 防风控建议

### 1. 账号保护
- ✅ 使用1年以上老号
- ✅ 开启设备锁（手机QQ → 设置 → 账号安全 → 登录设备管理）
- ✅ 绑定手机和邮箱
- ✅ 定期改密码（3-6个月）

### 2. 发送频率控制
已在本代码中实现：
- 赛前提醒：每个环节只发一次
- 赛后结果：比赛结束后延迟30分钟再发
- 不会频繁刷屏

### 3. 网络环境
- ✅ 保持IP稳定（不要频繁切换）
- ✅ 使用国内服务器（阿里云/腾讯云）
- ❌ 不要使用国外IP

### 4. 备用方案
- 准备2-3个备用QQ号
- 定期导出 go-cqhttp 的 session.token（实现快速切换账号）

## 🆘 被封号了怎么办？

### 轻度限制（临时冻结）
- 手机QQ上点击"解除限制"
- 发送短信验证
- 通常1-3天自动解封

### 中度限制（功能限制）
- 只能接收消息，不能发送
- 需要好友辅助解封
- 或者等待7-15天

### 严重封禁（永久封号）
- 很少发生，除非严重违规
- 申诉：腾讯客服小程序 → 账号问题 → 解封申诉
- 成功率较低

## ❓ 常见问题

**Q: 为什么一定要用老号？**  
A: 腾讯对新号风控很严，新号用协议登录很容易被识别为机器人。

**Q: 可以用主号吗？**  
A: **绝对不建议！** 一旦被封，可能影响你的正常使用。

**Q: 会被腾讯起诉吗？**  
A: 不会。最多封号，不会有法律风险。但不要用于违法用途。

**Q: go-cqhttp 会被封IP吗？**  
A: 一般不会，但频繁切换账号可能导致IP被临时限制。

**Q: 可以同时登录手机和 go-cqhttp 吗？**  
A: 可以，但建议：
- go-cqhttp 登录时选择"允许手机QQ在线"
- 不要在手机上频繁操作（可能踢掉 go-cqhttp）
